# シリアルモニタ

マイコンとの送受信を確認する小窓である。メニュー→「シリアルモニタ」で開く。

## 見えるもの

- **送受信の時系列**: Tx（PC→マイコン）と Rx（マイコン→PC）を時系列で表示する。受信は 1 つの読み取り役が配るため、開いたままにしても応答の横取りはしない。
- **フィルタ切替**: 「通常のみ」「全部」「mon のみ」「エラー・状態のみ」を切り替えられる。
- **有界キューと描画**: 窓内は有界キュー（上限 2000 行、120 ms ごとに最大 512 行を描画）とフィルタで絞る。溢れた古い行は破棄し、捨てた件数だけを状態欄へ表示する。
- **ファイル記録**: ファイル記録は `logger` へ残る。Rx は `info`、Tx は `debug` のため、既定では Rx 中心に残り、Tx は `debug` 有効時に残る。画面表示を一時停止したりクリアしたりしても、ファイルへの記録は止まらず消去もされない。

## 使い方

1. 接続した状態でメニュー→「シリアルモニタ」を開く。
2. フィルタで絞りながら流れを確認する（live Tx も全件キューへ積み、上限超過分は古い方から捨てる）。
3. 窓を閉じるとモニタだけ閉じ、接続はそのまま維持される。

## 注意

- 画面表示は有界キューとフィルタで絞られるため、正確な全量は保存先ファイルで確認する（Tx は `debug` 扱いである）。
- 重い描画で本体が遅くなる場合は窓を閉じる。
