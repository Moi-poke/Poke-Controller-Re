対象: 追加提案（簡略化・1行化・折りたたみ）。レビュー側はコードを見ていないため、**現行コードで確認できた事実**と、**提案の前提が違う箇所**を分けて整理する。

### 折りたたみの移動先

- 通信速度 → `接続(N)`。**失敗時だけ**シリアルタブに「速度を探す」を残す（現行の復旧導線は維持）。

## 4. レビュー提案への補正

- **「BCON の警告は常に表示」は誤り。** 警告は `接続モード・ペアリング` を開いたときだけ出る。確認ダイアログにも警告があるので、静的警告を削ってダイアログへ寄せる提案自体は妥当。
- **「タブ内のボタンが実行バーと重複」はまだ起きていない。** 実行バーは標準レイアウトに出ていない（コンパクトのみ）。`tabs_right` + 実行バーを入れた後に整理する。
- **シリアルの 1 行化は右列 523 物理＝418 論理（125%）、タブ内容 498 物理＝398 論理でぎりぎり。** `⟳` を 32px とすると見積もり約 434 物理。方式・ポートの表示名が長いため、実測前に「1 行で収まる」と決めない。
- **デッドゾーンの範囲は 0〜8192 ではない。** 実際は 0〜32767 の生軸。既定 1638 は 5%。UI の上限 8192 は 25% までしか設定できない。% 表示にするなら範囲も直すが、**上限は 50%（16383）**にする。100% はスティックが反応しない。
- **入力調停の選択肢は英語の内部値。** 設定ファイルの `off` / `human` / `script` は変えず、**表示名だけを対応づける**。

## 4.1 補足仕様（実装時に1行ずつ足す）

### 接続 / 再接続 / 切断

- ボタンは分けたまま。**接続中は `接続` を無効化**（または `接続済み`）し、`切断` だけ押せる。
- `再接続` は `接続(N)` メニューへ移す。現行の「接続 → 再接続」は、接続中に押すと通信を切り直すため、誤クリックの影響がトグルと同等。無効化で防ぐ。
- 接続失敗時は `接続` を再び有効化し、失敗理由の横に `速度を探す` を出す。

### シリアルの1行化

- `一覧更新` をアイコン `⟳`（約32px）にすると、現行見積もりから約66px 空く。
- それでも右列 498 物理（398 論理）に入らない場合は、表示名を短くする（`USB直結` / `Pico中継(USB)` / `Pico中継(プロセス)`）。正式名はツールチップ。
- 1行化の前に **498 物理（398 論理 / 125%）で実測**。入らなければ2行（方式 / ポート+接続）。

### 失敗時だけ出す復旧

- 表示条件: **最後の接続試行が `failed`**。
- 消す条件: **接続成功（`ready`）**、または**通信方式 / ポートを変更**したとき。
- `速度を探す` は失敗時だけ基本表示に出す。診断の `HELLO` / `PING` は `ツール(T)` に置く。

### スティックの遊び（デッドゾーン）

- 保存値は既存のまま読む（現行の保存値は 0〜8192 の範囲内）。UI の範囲を 0〜16383 に広げても、既存値の**挙動**は変わらない。ただし旧 UI で 8192 を 100% と思っていた場合は、25% と表示される。
- 表示は `%`。`pct = value / 32767 * 100`、`value = round(pct / 100 * 32767)`。丸めは 1 か所の関数にまとめる。
- 既定 1638 は 5%。スライダー + 数値入力（生値）を併用し、精度を残す。
- `config.complete_missing` の検証上限も **16383（50%）** に合わせる。100% を許さない。

### 入力調停の表示名

- 設定ファイルの内部値 `off` / `human` / `script` は変えない。
- 画面の表示名だけ `両方受け付ける（本家）` / `手動を優先` / `コマンドを優先` に対応づける。`applyArbitration` で表示名→内部値へ戻す。

## 5. 実装順（推奨）

0. **破壊的操作とラベルの確認（最優先）**
    - **0a. 破壊的操作**: `取込を破棄` と `ペア鍵を全削除` が同じ `T_KEY_DELETE` + `b""` を送る件。ファームウェアの 0x33 の意味を確認するまで、両方の確認ダイアログを同じ強さにし、`取込を破棄` の文言に「ペア鍵も削除される可能性」を明記する。確認後、同じ操作なら統合、違うならフレームを分ける。
    - **0b. ラベルと動作**: `シリアルタブで接続し直す` がタブ移動 + 一覧更新だけの件。**実際に再接続する**か、`シリアルタブを開く（一覧更新）` に改名する。名前と動作を一致させる。
1. **文言・状態の修正**（低リスク）: デッドゾーン範囲 / 入力調停ラベル / `HELLO: 対象外` / 空表示 / 接続ボタン幅 / `Pico↔Switch` の BCON 限定 / `fps` 既定オフ / 手動入力の未接続非表示
2. **1 項目折りたたみの廃止 + メニュー移設**: 通信速度、診断、ゲームパッド調整、入力調停、マウス、BCON 色、保守
3. **1 行化**: コマンド検索、カメラ、オーディオ、コントローラ。シリアルは実測して 1 行 / 2 行を決める
4. **タブ統合**: カメラ + オーディオ、履歴 + コマンド。`tabs_right` と 640 の結果を見てから
5. **実行バー / 常設停止**を入れた後に、履歴の停止・重複ボタンを整理
