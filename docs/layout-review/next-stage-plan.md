その後、実測 4 項目を行い、Q2 の既定化と Q6 の保留分を決める。

## BCON 整理の追加範囲

BCON タブの折りたたみ整理と同時に、次を必ず含める。

1. **1列化**: 状態 → 操作 → 折りたたみの順。折りたたみは下に全幅でまとめる。左列の幅と左右の上端ずれは、これで解消する。
2. **見出しの強弱**: 区切りの見出しを太字（Body Strong 相当）にし、項目名は通常の文字にする。
3. **余白の定数化**: 4px の刻み（4・8・12・16・24）。同じグループ内は 4〜8、グループ間は 16〜24。`PAD_EDGE` / `GAP_GROUP` などの定数にして各所の直接値を置き換える。
4. **押せない理由**: `状態を更新` が押せない理由を横に短く出す。未接続時の `Switchへ再接続` の扱いも揃える。
5. **表記の統一**: 未接続は `—`。接続中で読めないときだけ `未確認`。`なし` は機能がないときだけ。`未受信` も同じ規則に合わせる。
6. 既存の 5 項目: 「操作」見出しの削除、左列幅、`本体色` / `通信テスト` の名前、`—` 表示、LED の高さ。
