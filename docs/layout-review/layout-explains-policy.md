# レイアウトに説明させる方針

説明文やセカンダリラベルを足す前に、**配置・順序・まとまり・整列・近接・状態**で意味が伝わるようにする。ラベルは「何の項目か」を名付けるために使い、文章で説明しない。

## 原則

- **まとまり**: 同じ目的の操作を同じ見出しの下に置く。関連する設定を離さない。
- **順序**: 上から下、左から右へ、作業の順（状態 → 操作 → 詳細）に並べる。
- **近接**: 状態・理由・次の操作を、対象の操作のすぐ隣に置く。別タブやツールチップだけに逃がさない。
- **整列**: ラベルは入力欄の上か左に統一し、列を揃える。入力幅は内容の長さに合わせる。
- **状態**: 押せない操作は disabled にし、押せる操作との差を配置で見せる。必要なら理由を最短の語で添える。
- **現在値**: 折りたたみの中だけに置かず、状態バーや見出しの外へ出す。
- **説明文を足さない**: ラベル名と配置で分かるなら、文章・セカンダリラベル・ツールチップを増やさない。長い説明はツールチップへ。
- **状態と理由は残す**: 今の状態（接続方式・種別など）と、押せない理由・次にすべき操作は、説明文ではなく**対象の横に短い状態表示**として出す。消すと画面のどこにも情報がなくなるものは消さない。

## 適用例

| 箇所 | レイアウトでの説明 |
|---|---|
| デッドゾーン | `スティックの遊び` の直下に数値、右に `5.0%`。既定値は値そのもの。説明文は置かない |
| 接続 | ポート選択の直下に接続ボタン。未選択なら disabled。理由は上部の通知か、ボタンの近接位置 |
| BCON 接続方式 / 種別 | 折りたたみの外の状態バー（`Pico↔Switch`）と、`コントローラ状態` の並びで示す。追加の説明行は置かない |
| 入力調停 | `コマンド実行中の手動入力` の直下に選択肢。選択肢名で意味を伝える |
| 読み取り状態 | パッド選択の隣に ●/○ と短語。独立行を増やさない |
| 失敗時の復旧 | 接続ボタンの直下に失敗理由、その隣に `速度を探す` |
| フィルタ | ツールバーに `フィルタ ON`。設定はカメラタブの同じ並び |

## 例外

- **押せない理由と次にすべき操作は、対象の横に短い状態表示として出す**（例: `ポートを選ぶと接続できます`、`有線では削除できません。無線で起動してください`）。
- 今の状態（接続方式・種別）は、折りたたみの外の状態行として残す。
- エラー・失敗理由・禁止理由は、レイアウトだけでは伝わらないので短い文を許す。
- アクセシビリティ（スクリーンリーダー）と初回利用者向けの説明はツールチップに置く。
- 破壊的操作の確認はダイアログで行う。

## やめること

- 説明文を消して、位置だけで意味を推測させる。
- 何でもセカンダリラベルやツールチップで補う。
- 折りたたみの中だけに現在値や状態を置く。
