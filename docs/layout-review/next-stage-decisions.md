## 1. 確定した事実

### 1.1 `0x33`（BCON KEY_DELETE）

- 仕様: `Moi-poke/Switch-bcon` `spec/protocol_v3.md` — `0x33 KEY_DELETE / PC→Pico / LEN 0 / Classicリンク鍵全削除`。
- 実装: `src/main.c` の `FX_KEY_DELETE` は `gap_delete_all_link_keys()` と `store_host_forget()` を実行。
- **取込（`BCW1`）は消えません。** `TAG_CAP` には触れません。
- UI 側は重複していた `取込を破棄` を削除し、`ペア鍵を全削除` 1 つに集約。確認文に「取込は残る」を明記。**有線モードではボタンを無効化し、理由を表示（実装済み）**。
- 有線起動時は `s_bt_init == false` のため、鍵削除はスキップされ host タグだけ消える。**有線ではボタンを押せなくする（実装済み）**。

### 1.2 DPI

- `tk scaling` は **1pt（1/72 inch）あたりの px**。125%（120dpi）では `120/72 = 1.666`。DPI 倍率は `winfo_fpixels("1i") / 96 = 1.25`。
- 修正前の実測:
  - SDL（既定）: process awareness **0（DPI unaware）**、window 96dpi、Tk scaling 1.333、画面は 3072×1728 に仮想化。
  - GDI: GDI surface が Tk 初期化後に `SetProcessDPIAware()` を呼び、awareness 1 になるが、Tk scaling は 1.333 のまま。window だけ 120dpi になり、UI が小さくなる。
- `Window` の Tk 作成前に `SetProcessDPIAware()` を呼ぶよう修正:
  - 実測: awareness **1（system aware）**、window 120dpi、`winfo_fpixels("1i")=120`、Tk scaling 1.666、画面 3840×2160。
- これは **system DPI aware**。モニタ間で DPI が変わっても OS がビットマップ拡大縮小し、`WM_DPICHANGED` は不要。
- per-monitor にする場合は、Tk 作成前に `SetProcessDpiAwareness(2)` を呼び、`WM_DPICHANGED` を受けて再配置する。CustomTkinter は `SetProcessDpiAwareness(2)` + `GetDpiForMonitor` の 100ms ポーリングで追従している。

## 2. 決めてほしいこと

### Q1. DPI 方針

- A: **system DPI aware のまま**（現状）。単純。モニタ移動時は OS が拡大縮小（ややぼやける可能性）。
- B: **per-monitor DPI aware**。Tk 作成前に awareness 2、`WM_DPICHANGED` またはポーリングで再配置。くっきりするが、Tk の再配置・SDL/GDI 面のサイズ・ウィンドウ位置の扱いが増える。
- 判断材料: 複数 DPI モニタを使うか。150% 環境で既定化するか。

### Q2. 既定レイアウト

- A: 現行 `log_right` のまま。コントローラはスクロール。
- B: `side`（映像 + 右にタブ/ログ）。映像は約 1.83 倍になるが、右列でタブとログが高さを分けるためコントローラはまだスクロール。
- C: 新 `tabs_right`（`H[V[preview, log], tabs]`）。タブが全高になり、コントローラが収まる見込み。ログは左列の映像下（約 180px）。
- D: C + 実行バー。開始/停止/選択を映像下に常設。
- 併せて: 新規だけ既定変更か、既存ユーザーも移行するか。

### Q3. `tabs_right` の幅・高さ

- 右列は固定幅か、比率か。固定なら **論理px** で保存。
- パッドの許容縮小率: **0.9**（右列 **415 論理** / 125% で **519 物理**）か、**1.0**（**457 論理** / **571 物理**）か。
- 左列最小: 380 論理（映像 380×214）でよいか。
- 幅のフォールバック: `W_logical < right_min + left_min + sash`（sash 約 4.8 論理）で `log_right` + ログ非表示。ヒステリシス 40 論理px。
- 高さ条件は「パッド下端が見えること」（約 336〜346 / 125%）。720 も 600 も可。全内容が収まることは条件にしない。

### Q4. ログの高さ・ピン留め
