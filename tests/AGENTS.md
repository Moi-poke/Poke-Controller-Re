# tests/ — 実機なしで走る単体検査

ここは COM ポートもカメラも要らない検査だけを置く。実機が要る確認は
[`tools/probes/`](../tools/probes) の計測器で行い、pytest には入れない。

## 書くときの決まり

- ファイル名は `test_*.py`。共有の偽物は [`fakes.py`](fakes.py) と
  [`conftest.py`](conftest.py) に置き、各テストで作り直さない。
- 確かめるのは振る舞い・境界・失敗の型。実装の言い換え、ソース文字列の照合、
  「例外が出ないこと」だけの検査は書かない（壊れても気づけない）。
- 同じ入力を2回確かめる行を増やさない。1つの検査は1つの理由で落ちるようにする。
- 時間に依存する検査は、実時間を待たずに時計かイベントを差し替える。
- 落ちるテストを残さない。直せない事情があるなら、その場で報告する。

## 検査

```
task test                       # 全件（-n 4 で並列）
task test -- -k <expr> -q       # 絞り込み
```
